# confluent-handson

Laboratorio hands-on de **Confluent Platform** (en castellano), adaptado de la guía «Quick Start for Confluent Cloud».

- `laboratorio_confluent.html`: laboratorio completo (ábrelo en el navegador).
- `datagen-users-connector.json`: configuración del conector Datagen (reemplaza `<ip>` y `<password>`).
- `img/`: capturas de pantalla del laboratorio.
- `cloud_guide.md`: guía original de Confluent Cloud usada como base.
